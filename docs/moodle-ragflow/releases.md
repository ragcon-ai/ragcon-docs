# Releases

Public releases of the Moodle RAGflow Suite, newest first. Each entry is the release changelog for that
version. The plugins are versioned independently; at the initial launch all five ship together as **0.7.0**,
and later they evolve on their own SemVer lines.

Each plugin's full history also lives in its own repository (the `## Changelog` section of its README) and
on the [Moodle plugins directory](https://moodle.org/plugins) once published.

## 0.7.0 — Initial public release

The first public release of the suite: the **RAGflow AI provider** plus the **Tutor block**, **Search
block**, **Helpdesk placement** and the optional **Usage dashboard**. See each [plugin page](index.md) for
its features and settings.

- **AI provider (RAGflow)** `0.7.0` — initial public release: the shared backend (chat, search, sources,
  optional conversation + long-term memory) configured as a Moodle AI-provider instance.
- **Tutor block** `0.7.0` — initial public release: a per-course tutor chat with its own knowledge base.
- **Search block** `0.7.0` — initial public release: a knowledge-base search box returning ranked sources.
- **Helpdesk placement** `0.7.0` — initial public release: a site-wide help chat from the user menu.
- **Usage dashboard** `0.7.0` — initial public release: admin usage/health KPIs, charts and logs.
